# Source and use of the data

The reading references, reading titles, celebration names and calendar information in this repository come from the
English **Panchangam (liturgical calendar)** published by the Liturgy Commission of the Syro-Malabar Church
(https://www.syromalabarliturgy.org/liturgical_texts). Only the day-by-day calendar information is kept here, as data, so that
the church website and parish tools can show "today's readings" - **no Bible text** and **no copy of the PDF** is stored.
Every app that shows this data should say where it comes from and link to the Commission's page.

This repository is for parish information. If the Liturgy Commission asks for any change or removal, do it promptly.
The Malayalam names in `data/` are drafts until a Malayalam reader has proofread them.

The code (`tools/`, `tests/`, `examples/`) may be used and changed freely by the parish.
